Sales & Revenue Analysis Dashboard

📊 Project Overview

This project focuses on analyzing sales and revenue data using Power BI.
The dashboard provides interactive insights into sales performance,
revenue trends, top-performing products, and regional performance.

🛠️ Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX

📌 Key Features

- Total Sales KPI
- Total Revenue KPI
- Total Orders
- Units Sold
- Average Order Value
- Monthly Revenue Trend
- Top 10 Products
- Category-wise Sales
- Region-wise Sales
- Interactive Filters and Slicers

 📂 Dataset

The dataset contains sales transaction information including:

- Order ID
- Order Date
- Product
- Category
- Region
- Quantity
- Unit Price
- Sales
- Discount
- Revenue
- Payment Method

 📈 Dashboard

The dashboard helps identify:
- Top-performing products
- High-revenue categories
- Regional sales performance
- Monthly revenue trends
- Customer purchasing patterns

 🎯 Outcome

Built an interactive Power BI dashboard to transform raw
sales data into meaningful business insights.
