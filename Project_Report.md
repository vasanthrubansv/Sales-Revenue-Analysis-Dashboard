# Sales & Revenue Analysis Dashboard — Project Report

## 1. Introduction

This project presents an interactive sales and revenue analysis dashboard developed using Microsoft Power BI. The purpose is to convert transaction-level sales data into clear visual insights for business analysis.

## 2. Objectives

- Analyze sales and revenue performance.
- Track important KPIs.
- Identify top-performing products and categories.
- Compare regional performance.
- Study monthly revenue trends.
- Provide interactive filtering through slicers.

## 3. Dataset

The dataset contains 600 sample transactions covering one year. Each record includes order information, product details, region, quantity, price, discount, revenue and payment method.

## 4. Data Preparation

Power Query can be used to:
- Remove duplicates.
- Check data types.
- Handle missing values.
- Format dates.
- Validate numeric columns.
- Create calculated columns where required.

## 5. Dashboard Design

The dashboard contains KPI cards, a monthly revenue line chart, category and regional charts, a top-products ranking, a payment-method chart, and interactive slicers.

## 6. Key DAX Measures

The main measures are Total Sales, Total Revenue, Total Orders, Units Sold and Average Order Value.

## 7. Business Insights

The dashboard is designed to help users identify high-revenue products, stronger categories, regional differences and monthly changes in revenue.

## 8. Conclusion

This project demonstrates an end-to-end beginner-friendly data analytics workflow from raw Excel data to an interactive Power BI dashboard. It can be used as a portfolio project to demonstrate Power BI, Excel, Power Query, DAX and data visualization skills.
